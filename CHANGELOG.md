# Изменения

Версия (`KIT_VERSION` в `lib/core.sh`) повышается при каждом изменении скрипта: небольшие
изменения — последняя цифра (2.1.1), крупные — средняя (2.2.0). Все версии выходят в ветке `main`.

## 2.2.1

- Мастер «Установить Remnanode» больше не теряет введённое при выходе по Esc или при ответе «нет»
  на «Начать установку?». Ответы сохраняются в черновик (`/etc/remnanode-tools/draft-install.env`,
  права 600) и подставляются при следующем входе, даже после перезапуска `rnt`. Черновик удаляется,
  когда установка начата. Другие пункты меню черновик не видят и в конфиг его не сохраняют.
- Галочки «Кастомное ядро» и «Логи Xray» при повторной установке берутся из сохранённого конфига, а
  не всегда включены.

## 2.2.0

- Новый пункт «Обновить Remnanode и nginx» (и `rnt node-update`): скачивает свежие образы и
  перезапускает только те контейнеры, у которых образ действительно обновился. nginx обновляется
  всегда, нода — только при теге `latest` или `dev` в её docker-compose; закреплённая версия не
  трогается. В скрытном режиме образ ноды заново переклеивается на нейтральное имя. Старые образы
  удаляются, в конце — отчёт: обновлён или уже последняя версия.

## 2.1.3

- Главное меню при запуске один раз сверяет версию с GitHub. Если там новее, у пункта
  «Обновить remnanode-tools» появляется значок «↑ версия». Версии сравниваются по номерам, а не по
  строке: старая версия на GitHub не считается обновлением.

## 2.1.2

- «Обновить remnanode-tools» сначала сравнивает версии: показывает установленную и версию на
  GitHub, предлагает «Обновить 2.1.1 → 2.1.2» или сообщает, что стоит последняя. После установки
  называет новую версию и перезапускает меню. `rnt update` из консоли меню не открывает.
- README: убраны раздел о версиях и лишняя пометка про ufw.

## 2.1.1

- Возврат в меню по Esc мгновенный: главный экран и статистика блок-листов берутся из кэша и
  пересчитываются только после действия (раньше каждый возврат занимал 1–2 с).
- В файлах, которые скрипт создаёт на сервере (nginx, nftables, sysctl, systemd, sshd, помощники,
  конфиги), больше нет комментариев. Код тоже без комментариев.
- Репозиторий: `Rxxich/remnanode-tools`.

## 2.1.0

**SSL-сертификат** — новый пункт главного меню и шаг мастера установки (`modules/certs.sh`):

- HTTP-01 через acme.sh: проверочные файлы отдаёт nginx ноды на порту 80, продление идёт без
  остановки сайта. Если порт 80 свободен, на время проверки поднимается временный nginx; если его
  занял чужой процесс, продление не начинается, причина пишется в журнал и в Telegram.
- DNS API через acme.sh: Cloudflare, Gcore, Bunny, Selectel, Timeweb, Reg.ru, Beget, Yandex Cloud
  и любой другой плагин acme.sh; можно wildcard. Ключи — только в окружении acme.sh.
- Свой сертификат: загрузка через scp или вставка текстом. Проверяются формат, пара ключ–сертификат,
  домен, срок и цепочка.
- Прежние способы (TLS-ALPN на 8443, Cloudflare через certbot) остались.
- Меню: срок и издатель, «Продлить сейчас», «Сменить способ», «Проверить автопродление» (для certbot —
  пробный прогон), уведомления в Telegram (напоминание до конца срока, сообщение о продлении).
- При смене способа старое продление отключается, чтобы не перезаписать новый сертификат.
- Исправлено: у TLS-ALPN хуки ufw для порта 8443 не сохранялись acme.sh (передавались в
  `--install-cert`, а он их не принимает) — теперь передаются при выпуске.

**Интерфейс**

- «Назад» отовсюду: Esc / q / ← в меню, чек-листах, полях ввода, вопросах «Да/Нет» и при вводе
  SECRET_KEY. Мастер установки и защиты при выходе возвращает настройки как были. После возврата
  лишний Enter не нужен.
- Поле ввода — свой редактор строки: ← → Home End, Delete, Ctrl+U, длинные ссылки прокручиваются.
- Исправлено: `ui_input` и `ui_secret` не могли записать результат в переменную вызывающего, если
  она называлась так же, как их внутренние (`val`, `cur`…).

**Блок-листы**

- Выбор интервала обновления: 1, 3, 6, 12 часов или раз в сутки.
- Если в «Какие списки блокировать» ничего не поменять, правила не пересобираются.

**Прочее**

- nginx отдаёт `/.well-known/acme-challenge/` на порту 80 (для HTTP-01).
- Убран перенос настроек со старого однофайлового установщика.
- README: картинка главного меню, раздел о сертификатах.
